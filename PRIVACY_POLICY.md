# Cloud Finder – Privacy Policy

Last updated: September 30, 2025

This Privacy Policy describes how the Cloud Finder Chrome Extension handles the information of its users.

## 1. Data Collection and Processing

The Cloud Finder extension is designed to provide quick access to popular cloud services.

**No Personal Data Collection:** We want to be absolutely clear: The Cloud Finder extension does not collect, store, transmit, or process any personal or non-personal data from the users.

**No Tracking:** The extension does not use any cookies, web beacons, or tracking technologies.

**No External Communication:** The extension does not communicate with any external servers, aside from opening the public URLs of the cloud providers after a user-initiated click.

## 2. Permissions Used

The extension requires minimal permissions to function:

- **activeTab:** This permission is used exclusively to open the selected cloud service link in a new browser tab or window, based on a direct user click. It does not grant access to the content of the currently active tab or any other website history.

## 3. Changes to this Policy

We reserve the right to update this Privacy Policy at any time. We will update the "Last updated" date above to reflect the changes.
